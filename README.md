# Наша маленькая история — сайт для Веры

Личный сайт-история: 10 глав, настоящие фотографии и скриншоты переписки, финальное поздравление с днём рождения.

Исходный `Code.txt` обрывался на середине `App.tsx` и не содержал `styles.css`, поэтому проект был собран заново: восстановлен недостающий код, подключены реальные фотографии из папки и улучшены интерфейс, навигация и адаптивность.

---

## Быстрый старт

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

Сборка и локальный просмотр готовой версии:

```bash
npm run build
npm run preview
```

## Где что менять

### Тексты, главы, фото — `src/content.ts`

- `site` — имя, подписи, музыка, финальные строки.
- `photos` — пути к изображениям.
- `intro` — вступление.
- `chapters` — все 10 глав. У главы можно указать:
  - `photo` — главное фото;
  - `chat` — скриншот переписки;
  - `gallery` — дополнительные кадры;
  - `interactive` — `invite`, `nutella` или `hearts`;
  - `secret` — секретное послание по звёздочке;
  - `side` — с какой стороны фотография на широком экране.
- `final` — финальное поздравление.
- `gallery` — фотоальбом после глав (подписи, порядок кадров).
- `secretAlbum` — скрытая папка «Секрет» в конце фотоальбома.
- `letter` — письмо в конверте «Для тебя».
- `site.finalLine` — главная строка финальной сцены.

### Музыка — `src/music/`

Песня берётся прямо из папки `src/music/`. Чтобы поставить или заменить музыку, просто положите туда аудиофайл — менять код не нужно.

1. Поддерживаются `mp3`, `m4a`, `aac`, `ogg`, `wav`, `flac`.
2. Если файлов несколько, играет первый по алфавиту. Чтобы заменить песню — удалите старую и положите новую.
3. Музыка запускается по кнопке **«Начать нашу историю»** и играет по кругу. Отдельной панели нет — только маленькая кнопка динамика в верхней панели.
4. Громкость по умолчанию — `site.music.volume` в `src/content.ts`. Полностью отключить музыку можно через `music.enabled: false`.

Пока папка пуста, сайт работает как обычно, просто без звука. После добавления файла пересоберите сайт (`npm run build`) или запушьте изменения — GitHub Actions сделает это сам.

## Что улучшено по сравнению с исходным кодом

- Полностью переписаны все 10 глав: короче, живее, без повторов; сохранены реальные события и детали.
- Десятая глава заменена на «И это только начало» — без конфликтов и обид.
- Новая тёмная «ночная» тема: чернила, пыльная роза, золото, зерно, мягкие свечения.
- Подключены все 7 реальных изображений из папки; добавлены фотоальбом после глав и галереи в главах.
- Полностью адаптивная вёрстка: телефон, планшет, десктоп.
- Навигация: кнопки «Назад / Дальше», стрелки `←` `→`, свайпы на телефоне.
- Прогресс истории и счётчик глав в верхней панели.
- Лайтбокс: клавиши, стрелки, точки, свайпы, подписи, закрытие по Escape и фону.
- Приближение фото в лайтбоксе: щипок двумя пальцами и двойной тап на телефоне, кнопки «− / +» и клавиши `+` / `−` на компьютере.
- Скрытая папка «Секрет» внизу фотоальбома — три личных кадра, которые открываются только по нажатию.
- Запоминание места в истории (`localStorage`) и кнопка «Продолжить с главы N».
- Интерактив: мини-приглашение с выбором времени и места, открывающаяся баночка Nutella, сердечки.
- Секретные послания по звёздочке.
- Конверт «Для тебя» с письмом, которое проявляется построчно.
- Музыка из папки `src/music/`: стартует с кнопки «Начать нашу историю», играет по кругу, отключается кнопкой динамика в верхней панели.
- Полноэкранный режим для всего сайта и для просмотра фото.
- Финальная сцена «Это только начало нашей истории» со звёздами и мягким свечением.
- Бережное отношение к `prefers-reduced-motion`, `focus-visible`, `aria`-атрибутам и клавиатуре.
- Плавные появления текста и фотографий при прокрутке.

## Публикация на GitHub Pages

Сайт уже опубликован: **https://novikov81969.github.io/nasha-istoriya/**

Репозиторий: **https://github.com/novikov81969/nasha-istoriya**

Публикация автоматическая: при каждом пуше в `main` GitHub Actions собирает проект и выкладывает `dist` на GitHub Pages (`.github/workflows/deploy.yml`). Отдельно собирать и куда-то копировать ничего не нужно.

Проверить или перезапустить сборку: вкладка **Actions** в репозитории → workflow **Deploy to GitHub Pages** → **Re-run jobs**, либо:

```bash
gh workflow run deploy.yml
```

В `vite.config.ts` стоит `base: './'`, поэтому сборка корректно работает из подпапки вида `https://username.github.io/repo/`.

## Важно

Это личный подарок. Сайт и репозиторий сейчас **публичные**: переписка и фотографии доступны любому, у кого есть ссылка, и могут попасть в поисковики (в `public/robots.txt` индексация закрыта, но это не гарантия).

Скрытая папка «Секрет» — это кнопка, а не пароль: файлы лежат в `public/images/` и доступны по прямой ссылке. Если нужна настоящая защита личных кадров, репозиторий лучше сделать приватным (тогда GitHub Pages отключится).

Если захочется закрыть: сделайте репозиторий приватным (`gh repo edit --visibility private --accept-visibility-change-consequences`) — GitHub Pages при этом отключится, и сайт останется доступен только локально через `npm run preview`.
